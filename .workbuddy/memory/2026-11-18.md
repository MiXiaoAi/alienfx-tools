# 2026-11-18

## alienfx-tools 界面汉化（简体中文）

对 Win32 项目 alienfx-tools（Alienware 灯效/风扇/监控工具）做了简体中文界面汉化，共改动 21 个文件。

关键信息：
- 三个 GUI 均为 MBCS（非 UNICODE）构建，`CharacterSet=NotSet` 且无 `/utf-8`，因此窄字符串界面文本依赖系统 ANSI 代码页（本机 936）。
- .rc 资源文件原本就是 UTF-16LE + BOM，翻译后保持该编码，字符集改为 `LANG_CHINESE, SUBLANG_CHINESE_SIMPLIFIED`。
- 对话框字体由 `FONT 8, "MS Shell Dlg", ..., 0x1` 统一改为 `FONT 9, "Microsoft YaHei UI", ..., 0x86`（GB2312_CHARSET），共 26 处；布局全部为 DLU/相对矩形计算，随字体同比缩放，未改任何控件坐标。
- 代码中的界面字符串（列表列头、下拉项、托球通知、确认框）翻译后含中文的 .cpp 保存为 **UTF-8 with BOM**：MSVC 依 BOM 识别源编码，执行字符集仍取系统 ACP，A 版 API 可正确显示。若在非中文区域（ACP≠936）编译，需加 `/execution-charset:.936`。
- 只翻译界面文本；DebugPrint 调试日志、注册表键名、WMI 查询、文件名、库名保持英文。
- 未翻译：README.md / Doc/*.md 文档、alienrgb-cli / alienfan-cli 命令行输出（如需再做）。

汉化脚本思路：Python 按“带引号的完整字符串字面量”做精确替换，逐文件替换表，结束后检查未匹配条目与 BEGIN/END、DIALOGEX 数量、引号配对。

## GitHub Actions 自动构建

新增 `.github/workflows/build.yml`：windows-2025（VS 2026）构建 alien-tools.sln 的 Release|x64，产物打包为 alienfx-tools-win64 artifact；推送 `v*` tag 时用 gh 自动创建/更新 Release 并附 zip。README 加了构建徽章。

关键适配点：
- 全部 vcxproj 把 VCToolsVersion 固定为 14.50.35717（本地 VS 18.6 的 MSVC），CI 上会因版本不存在而失败——workflow 用 vswhere 检测 runner 实际 MSVC 版本，以 `-p:VCToolsVersion=` 全局覆盖。
- alienfan-SDK / alienfan-low 用 WindowsApplicationForDrivers10.0（WDK 工具集）+ WDK/SDK NuGet 包（packages.config），runner 镜像自带 WDK VS 扩展，但需先 `nuget restore ... -PackagesDirectory packages` 到仓库根 packages\。
- Install.vdproj 不被 MSBuild 支持（MSB4078 警告），已用 -warnasmessage 降噪；msi 安装包未纳入 CI。
